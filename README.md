# schedulingSoftware

Scheduling and resource-allocation tool for a growing US M&A Tax advisory team: pipeline intake → effort estimation (hours by level) → time-phased staffing → weekly capacity visibility, with a NetSuite actuals feedback loop.

**Current status:** design phase — no application code yet.

See **[PLAN.md](PLAN.md)** for the full design plan: current-state analysis of the existing Excel tracker, target data model and scheduling engine, the two-track (workbook + web app) delivery plan, and the open discovery questions.
